It is vendored so `./build.sh` works without network access; Gradle consumers
resolve the same version from JitPack instead.

## AriaCoda

No AriaCoda code is included in this library. The ARCOS protocol implementation
in `arcos/` was written from the protocol description — packet framing, checksum,
argument tagging, command numbers and the SIP field order — and verified against
frames generated by AriaCoda.

`tools/golden_vectors.cpp` is the verification harness. It is the one file that
`#include`s AriaCoda headers and links `libAria`, so building **that tool**
involves AriaCoda's GPL-2.0 terms. It is a development aid: it is not part of the
library, is not shipped in the `.aar` or `.jar`, and nothing in `arcos/` depends
on it. `tools/golden_vectors.txt` is its recorded output, checked in so the test
suite runs without AriaCoda present.

AriaCoda lives at <https://github.com/reedhedges/AriaCoda>.
